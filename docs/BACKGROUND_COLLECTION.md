# 后台独立浏览器采集

## 当前行为

在工作台添加商品链接并填写研究需求。模型先读既有证据，缺少关键资料时调用 `collect_product_page`：后台启动独立的无头 Chromium，打开任务中的淘宝、天猫或京东商品链接，等待动态内容，有限次滚动，运行共享 DOM/JSON-LD 解析器，校验并追加快照，再把新证据交还模型。无需用户打开商品页，也不依赖扩展更新。

这仍是按需求使用工具的 Agent：由模型决定是否采集以及采集哪件商品，程序校验归属并执行。不会仅因为新增链接就自动启动研究；请点击“开始研究”。旧的暂停研究可回答“请使用后台采集工具打开链接重新核实”后继续，历史报告不会重写。

`capture_product_page` 保留为扩展接管工具，只有该通道需要已打开并连接扩展的商品页。两条通道复用 `frontend/src/extension/capture-adapters.ts`，保留规格、价格原文、来源、时间和缺项；图片仅存来源引用与尺寸。后台新增受控规格选择与核验，见 [自动规格核验](AUTOMATIC_VARIANTS.md)；不搜索、不点击购买、不读取图片内容。

## 安装与恢复（WSL）

~~~bash
cd backend
uv sync --all-groups
uv run playwright install --with-deps chromium
sudo apt-get install --no-install-recommends fonts-noto-cjk
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
~~~

`--with-deps` 会安装 Chromium 所需系统库。当前 Ubuntu 22.04 已实际安装 Playwright 1.64.1、对应 Chromium，并补齐缺失的 `libgbm1`、`libasound2` 及其依赖。没有更改系统代理或全局 Python/Node。Windows 本机独立运行未验收。

中文页面还需要 CJK 字体。当前已补装 `fonts-noto-cjk`：此前 WSL 没有中文字体，淘宝登录窗口的中文和标题栏显示为方框；二维码与布局仍可显示。安装后新 Chromium 测试页实际使用 Noto CJK 渲染中文。已有窗口若仍显示方框，完成当前操作后在工作台关闭并重新打开登录窗口以更新字体缓存；不要为了字体问题清除认证资料。此修复不代表账号登录或商品采集已完成。

共享解析器运行资产为 `backend/app/browser_assets/collector.js`，需随源码交付；后台运行不依赖 Node。修改适配器后从项目根执行：

~~~bash
cd frontend
npm run build:collector
npm run typecheck
~~~

`GET /api/v1/collection/status` 验证浏览器能够启动及解析器文件存在，不代表平台登录或商品字段完整。页面显示后台环境与每次工具实际访问结果。

根目录 `.env` 配置：`SHOPPING_AGENT_BROWSER_TIMEOUT_SECONDS` 默认 55 秒（15–120）；`SHOPPING_AGENT_BROWSER_MAX_SCROLLS` 默认 6（0–12）。每研究采集/规格目录读取最多 3 次，规格选择核验另最多 3 次；加入搜索候选后两类上限各扩展至 6 次，并发最多 2 个；外层研究片段仍有 180 秒上限。生产采集在独立 Python 进程执行，父进程每约 150 毫秒检查取消与期限；超时回收本次工作进程及已跟踪的浏览器后代，额外预留数秒清理。无需等阻塞的 Playwright 回调返回；不承诺操作系统层面的瞬时终止。解析器的受控 DOM 测试可在进程内注入固定页面，另有真实子进程集成检查。

本机 TUN DNS 将平台域名解析到 `198.18.0.0/15`。默认网络校验拒绝该非公网范围；已在私有 `.env` 中启用 `SHOPPING_AGENT_BROWSER_TRUST_FAKE_IP_DNS=true`。此模式仅解析并校验 IPv4 地址，并在隔离 Chromium 中关闭 IPv6，避免 WSL 同时返回 Fake-IP IPv4 与非公网 IPv6 时误拒绝，也避免浏览器转向未校验的 IPv6 地址。IPv4 仍必须是公网地址或 `198.18.0.0/15`；其他内网地址不允许，HTTPS 证书校验保持开启。只在信任本机 Fake-IP 路由时启用，其他环境保持 false。

## 登录与验证

工作台现在提供可见登录接管：后台采集受阻后，在研究记录旁点“打开登录窗口”，后台会在服务所在电脑启动独立可见 Chromium，访问对应商品页并允许平台展示登录/验证。手动完成后回工作台点“已完成登录，保存并继续研究”；保存成功才向暂停运行提交继续请求，Agent 使用后台工具重新访问核实。无需输入终端命令，也无需更新扩展。保存会话不等于确认登录成功，更不等于确认商品规格。

同时只允许一个登录窗口；同一商品重复点击复用该窗口，其他任务不能读取或控制。10 分钟后自动关闭；取消不保存新状态。认证状态只保存淘宝/天猫或京东域的 Cookie、localStorage、IndexedDB，接口与模型不接收这些内容。窗口在后台服务所在电脑显示；远程无图形桌面服务会返回明确失败。WSL 当前已实际验证有 WSLg，真实可见 Chromium 的合成页面启动与保存检查通过，实际账号登录仍由用户完成。

后台与日常 Chrome/Edge 登录态独立。登录跳转、安全验证、HTTP 401/403/429、非同一商品页或未出现商品区域会保存 `page.access` 访问证据，状态为 blocked；浏览器异常保存 failed，不将登录页标题作为商品证据。它不会绕过验证码或尝试账号密码。

还可在有图形桌面的 WSL 终端由用户执行备用脚本：

~~~bash
cd backend
uv run python -m scripts.browser_session taobao
# 京东另行执行：
uv run python -m scripts.browser_session jd
~~~

弹出独立浏览器后自行登录、处理验证，回终端按 Enter 保存；Ctrl+C 取消。状态保存在应用数据目录的 `browser-sessions/taobao.json` 或 `jd.json`，淘宝与天猫共用 taobao 状态。写入使用临时文件与原子替换，Unix 权限 0600。不会读取或复制已有 Chrome/Edge 配置。状态含认证资料，不得分享或提交；可删除对应文件撤销后台本地保存，平台端会话撤销需在平台自行操作。没有图形桌面、状态失效或平台再次验证时，可使用扩展接管。该人工登录流程尚未用真实账号验收。

## 执行与恢复边界

- 工具只接受任务内 `item_id`，程序从数据库读取链接并规范到已知商品域名，去掉追踪参数；保留原链接中可识别的 SKU 提示，但不保证平台会选中该规格。
- 商品、资源域名限定为平台及列出的 CDN，HTTPS/端口/DNS 地址受校验；HTTP 重定向逐跳检查，最多 6 次。WebSocket 路由保留在本地，不调用远端连接，也不在同步回调中关闭连接；服务工作线程及下载禁用。它是受限采集器，不是可访问任意 URL 的开放浏览器。
- 登录页正文不作为商品快照；访问证据仅保存静态错误标记，不保存账号文本、Cookie 或登录页截图。
- `(run_id, tool_call_id)` 哈希形成稳定操作标识。已保存快照的检查点重放直接读取同一快照，不再访问页面；浏览器已读但尚未提交时进程崩溃，恢复可能重新执行只读访问，不承诺网络请求恰好一次。
- 操作上限按持久化尝试记录计数；同一调用不能换商品/参数。保存前在写事务核对运行状态，已取消的运行拒绝晚到结果。未保存的网络失败也记为一次尝试。

## 验证记录（2026-10-28）

- 用户真实研究曾卡住数分钟，两个研究线程栈均停在同步 WebSocket `close()` 回调，原动作超时未能退出。移除同步关闭并增加父进程监督。后台累计 37 项检查通过，包含真实 Chromium 发起 WebSocket 后采集完成、故意挂起的工作进程/浏览器后代在超时或取消后回收，以及异常结果处理。新增 `psutil` 用于跨平台跟踪本次进程树，不按进程名批量结束浏览器。
- 修复后用用户已有天猫链接及私有会话真实复测：约 7.48 秒返回 partial，4 个字段、1 条价格记录。只记录汇总，不公开商品资料或认证状态；字段完整性与推荐质量仍待核对。旧服务与其卡住的浏览器已定向回收，私有数据库和 LangGraph 检查点已备份，当前研究从检查点续跑。
- 原有研究续跑已完成：新采集 7232 ms，后续模型调用 8290 ms，`submit_report` accepted，报告已保存。未新增重复任务，未恢复已取消研究；仍是部分商品证据，需要分别核对字段覆盖与推荐内容。

- 真实无头 Chromium + 受控合成动态 HTML：打开页面、等待价格变化、读取选中规格、滚动、共享解析、新快照入库与报告引用通过。不是模拟扩展。
- 后台 30 项检查通过；登录受阻、私网/域名限制、取消清理、三次上限、同操作重放不重复访问有回归检查。前端类型、网页/Chrome/Edge 构建与扩展 6 项检查通过。工作台提示可见、无未捕获脚本错误；Windows localhost 后台状态为 ready，采集环境 available。

- 真实配置网关 + 真实无头 Chromium + 合成页面：`read_product_evidence → collect_product_page → submit_report`，3 次模型调用、23.57 秒，报告引用新快照，无扩展通信。该测量不代表普遍性能或真实商品准确性。
- 用户已有真实天猫商品链接：后台自主访问后得到 `login_required`，blocked，0 条价格；证明访问与登录边界识别，尚未取得该商品有效参数。京东/淘宝、实际登录后的字段覆盖与推荐质量仍待真实验收。

学习数据流：模型工具调用 → 任务归属校验 → 独立浏览器 → 共享解析 → 快照校验与幂等保存 → 带引用结果 → 模型继续。关键知识：浏览器 context、动态渲染、来源证据、工具参数约束与检查点重放。修改练习：调整滚动上限，比较合成页面是否新增资料；失败案例：登录页必须返回受阻，不能凭页面标题报告商品规格。
