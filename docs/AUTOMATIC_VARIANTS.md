# 自动规格核验

## 产品行为

用户在工作台描述需求，Agent 可以自行读取可选规格、选择已登记的选项，等待选中状态与价格更新，再继续研究。无需打开日常商品页或更新扩展。遇到登录/验证仍使用现有独立窗口接管；目录缺失、禁用选项、多个合理匹配或未能核对选中状态时如实返回，不把点击当成成功。

工具链：`read_product_evidence` → `inspect_product_variants` → 模型按需求选择目录 ID → `select_product_variant` → 新快照与引用 → `submit_report`。模型也可先使用 `collect_product_page` 获取新资料；不固定强制工具顺序，但不能选择未读取的选项。

`inspect_product_variants` 读取规格组、选项文本、选中与禁用状态，并返回目录所在 `snapshot_id`。`select_product_variant` 只接受任务内商品 ID、目录快照 ID、`group_id`/`option_id` 和原因。程序检查归属、唯一分组、可操作性，再重新打开页面匹配 ID 和完整标签。每个动作前再次检查；目标唯一时使用 Playwright 原生点击和可操作性等待，不使用 force 或模型提供的选择器/JavaScript。

## 数据与界面

- `CaptureSnapshot` 增加可空的 `variant_catalog` 和 `variant_verification`，旧记录继续可读，无新增数据库迁移。缺省新字段不参与旧版 schema-v1 的幂等哈希，避免旧扩展重试冲突。
- 目录最多 12 组、每组 40 个、总计 160 个选项；截断明确标记，重复 ID/组或多选状态标为歧义。每个选项保留页面证据；实际选中属性进入 `selected_variant.attributes`。
- 规格状态与价格稳定后保存新快照；目录、选中属性、价格原文及核验状态同批保存。状态可为 selected、stale_catalog、unavailable、not_selected、page_changed、unstable。
- `same_page_state` 只表示选中后同页价格在观察期间稳定；不证明平台 API 已将价格绑定到具体 SKU，也不等于最终支付价。优惠前/券后/会员价仍保留原始条件。相关 SKU/详情/价格请求未完成、页面忙碌或状态仍变化时，不确认对应关系。
- 工作台显示规格选择核验结果、可展开目录和每组选中项；研究进度显示“读取可选规格”“选择规格并核验价格”。历史报告保留原内容。

## 执行边界

规格读取和选择仍运行在独立、受监督的后台进程，沿用默认 55 秒期限、最多 2 个采集进程和取消回收。每研究采集/目录读取共享 3 次上限，选择核验另有 3 次上限，每次最多 12 个分组。持久化尝试记录限制重试，保存后同一工具调用重放直接使用原快照，不再次点击。进程在保存前崩溃时可能重试浏览器内规格操作，不承诺网络访问恰好一次。

每次工具调用重开隔离浏览器；后续选择会先重放上个目录中其余分组的已观察状态，以保持分步选择的上下文，再应用本次选择。每个状态均重新查验，页面变化或选项禁用就停止。单次运行不会操作购物车、购买、支付、账号设置、数量或跨商品导航控件。

当前适配包括新版天猫 `skuItem/valueItem`、旧淘宝 `dl/dd` 和京东 `choose-attrs` 形态。真实样本验证了当前天猫页面；淘宝其他布局、京东实页、跨品类覆盖仍待扩大。需要跳转新 SKU 链接的选项当前标为不可原地操作；不把另一商品页归到原商品快照。目录超限或隐藏在尚未支持的面板内时保持部分覆盖。没有图片识别、替代品搜索或全平台任意页面操作能力。

共享解析器版本 `0.2.0`；Chrome/Edge 可选构建版本 `0.2.2`。后台功能无需扩展更新；若使用扩展手工采集也希望看到新版目录，则重新加载对应构建并刷新商品页。修改共享解析器后需执行 `npm run build:collector`，运行资产随源码保存。

## 伴读

关键代码：`variant-controller.ts` 读取受限 SKU 区域并登记目标；`variant_controller.py` 复核与操作；`research_agent.py` 校验目录归属、执行工具并登记引用；`schemas.py` 保证证据完整；`collection_process.py` 从外部监督浏览器退出。

练习：在合成页面增加一组包装规格，解释模型为何只能引用目录 ID，以及改变旧目录标签后为何拒绝点击。失败案例：按钮被点到但页面没有更新 selected 状态，工具必须返回 not_selected；不能仅以点击函数无异常判定成功。

参考：[Playwright 可操作性等待](https://playwright.dev/python/docs/actionability)、[Locator 定位](https://playwright.dev/python/docs/locators)。
