# 替代商品搜索与逐项核验

## 当前范围

2026-10-29 接入 `set_search_requirements → search_products → adopt_search_candidate`，候选加入现有任务后使用已有采集、规格核验和报告工具。模型决定查询、平台、候选与补查顺序；程序验证参数和证据。

在研究需求中说明“寻找其他品牌替代品”及硬条件即可。工作台显示提取出的硬条件、偏好、搜索范围、候选和核验结果。条件有误时可以停止后修改需求重新研究；Agent 提问时也可在回答中修正，再由模型更新条件。尚未提供运行中直接编辑条件表的交互。

搜索使用隔离 Chromium 和现有项目私有会话，入口固定为淘宝搜索与京东搜索；工具不接受任意 URL、脚本或选择器。搜索查询会发送给目标平台，返回文字会进入配置的模型上下文。详情图内容阅读仍未接入。

## 数据流与证据

1. 读取原商品证据，登记原商品 ID、编号硬条件与偏好。
2. 按平台和查询搜索当前第一页，最多记录五个直接商品链接；去除追踪参数并按商品身份去重。搜索页只作线索，不能直接成为商品事实引用。
3. 模型提交本次运行实际返回的搜索 ID 与候选 ID。后端验证归属，最多加入三个不同候选，任务仍最多二十件商品。不能由模型凭空生成候选 URL。
4. 候选加入与操作记录在同一事务提交；写入前锁定并核对运行状态。取消拒绝写入；同操作重放不重复加项。已保存搜索结果重放不重新访问网页；保存前崩溃可能重复只读访问，不承诺网络恰好一次。
5. 读取候选详情。报告为每个已加入候选逐项记录 `matched / unmatched / unknown`，不能省略失败候选。
6. 确认满足或不满足必须引用该候选本次已读的有效详情快照；品牌关系引用双方 `product.brand` 字段。旧快照、另一商品、搜索标题和访问受阻证据不能冒充当前详情证明。品牌别名和语义判断仍依赖模型，程序并非完整事实证明器。
7. 不同品牌且全部硬条件有证据满足才允许 `qualified`；明确不满足为 `rejected`，其他为 `needs_evidence`。没有合格候选时不能提交替代搜索成功的 `recommendation`。

原商品与候选共同进入确定性价格核算；价格更低本身不证明符合用途或全部硬条件。

## 边界与失败处理

- 每运行最多四次搜索、三个不同候选；每次搜索默认 55 秒，复用独立进程监督与取消回收。
- 加入搜索候选后，后台采集/目录读取和规格选择的上限各由三次扩展到六次；扩展接管仍最多三次。模型最多 24 次调用，单执行片段仍最多 180 秒。
- 只有页面明确表示没有结果才返回 `no_results`。登录/风控返回 `blocked`；空白、未加载、解析不支持或网络失败返回 `unavailable`，都不能等同于全平台没有商品。
- 仅抓取直接详情链接，不跟随广告跳转，不翻页，不自动处理登录或验证码。遇到受阻可换查询/平台，或结束为有明确限制的阶段性结果。
- 搜索页专用登录接管入口尚未实现；已有商品登录接管可建立同平台私有会话，但不保证搜索风控解除。

## 验证记录（2026-10-29）

- 16 项搜索检查：真实 Chromium 加载合成淘宝/京东页、可见链接、去重与数量限制、登录 iframe/验证遮罩、无结果、网络范围、搜索限额、候选归属、取消、原子写入与重放、暂停重启续跑、品牌和硬条件引用校验。
- 真实配置网关 + 真实 Chromium + 合成商品页：9 次模型调用、89.93 秒，完成搜索、加入候选、采集详情并提交合格候选。一次引用不符合候选详情规则被退回，模型修正后成功。此记录是协议和流程验收，不是实际商品推荐准确率。
- 真实平台只读探针：京东跳转 `cfe.m.jd.com` 风控路径；淘宝未识别到直接商品结果。均未获得真实合格候选，不记为搜索实采成功，不绕过验证。
- OpenAPI/TypeScript、网页与 Chrome/Edge 构建通过；扩展 6 项检查通过。合成工作台在 1440×1000 与 800×900 下无脚本错误及横向溢出，条件证据可展开；非用户人工验收。

## 伴读与练习

关键代码为 `product_search.py`（浏览器读取）、`search_runtime.py`（持久化操作与引用约束）、`search_schemas.py`（输入和逐项结论）、`ResearchSearch.tsx`（范围与结果呈现）。

学习顺序：先解释“搜索线索与详情证据”的区别，再跟踪一次搜索 ID 如何变成任务商品 ID，最后观察检查点恢复为何不会重复加入候选。修改练习：在合成页面增加第四个不同候选，验证三候选边界；再把一个必需参数删除，确保它变成待核实而非自动通过。

失败案例：模型引用原商品证据证明候选满足条件，程序会拒绝报告并返回修正理由。查看真实合成探针的该次退回记录，解释引用“存在”与引用“属于正确商品和当前快照”的区别。
