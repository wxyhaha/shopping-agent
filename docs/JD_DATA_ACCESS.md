# 京东数据访问：暂停与替代路线

## 当前决定（2026-11-02）

用户先报告专用浏览器被限制登录，随后确认日常浏览器也受限，最新明确本轮跳过京东。停止京东在线采集与登录尝试；不继续切换浏览器、复用认证资料或反复重试。先推进淘宝/天猫比较、真实替代搜索与交付验收，京东接口评估和资料导入暂缓，不作为本轮前置。

`SHOPPING_AGENT_JD_BACKGROUND_ENABLED` 默认 `false`。商品采集、规格后台操作、搜索及工作台/CLI 独立登录均在启动浏览器前检查；worker 内也检查，旧父进程漏传配置时仍采用暂停默认值。受控测试夹具使用明确的隔离输入，不访问真实京东。

暂停返回 `jd_automation_disabled`，不记为无商品或新采集事实。工作台显示暂停，隐藏京东独立登录入口；研究可以使用已有资料并输出 `needs_evidence`。历史价格只代表原采集时刻，不能当成现在可购买价格。淘宝/天猫已有路径不受此开关影响。

不要为恢复测试自行把开关改为 `true`。须由用户明确恢复授权，并重新核对真实访问与数据覆盖。

## 已有与未实现的资料入口

| 路径 | 当前事实 | 限制 |
| --- | --- | --- |
| 既有商品快照 | 可供 Agent 读取，保留来源与采集时间 | 不证明当前价格、库存或规格仍相同 |
| 研究中的文字补充 | 已有人工确认与 `user_statement` 引用 | 用户陈述不冒充网页采集或商家已核实事实 |

| 官方数据接口 | 已开始核对文档，未申请/连接服务 | 资质、授权、商品覆盖和字段语义需要实际验证 |

## 官方接口初步核对

京东公开 IOP 文档列出 `product/getDetail`：要求授权 token，并校验商品是否属于商品池；返回项包括品牌、参数、介绍，可请求结构化属性和详情介绍扩展字段。因此存在可评估的正式资料通道，但不能推断当前项目有调用权限，也不能保证任意京东零售 SKU 都覆盖。[京东商品详情接口文档](https://opendoc.jd.com/iopv2/iopv2/%E5%95%86%E5%93%81/%E6%9F%A5%E8%AF%A2%E5%95%86%E5%93%81%E8%AF%A6%E6%83%85.html)

京东联盟/JOS 入口可供进一步核对；本轮页面依赖动态加载，尚未完成资格、权限、价格或目标商品覆盖核验，不依据第三方转述承诺接入。[京东 JOS 联盟入口](https://jos.jd.com/jdunion)

下一次接入决策前，至少验证：申请资格与授权方式、两个目标 SKU 是否返回、选中规格与价格口径、字段来源及时间。未获得这些证据前不新增空壳工具、不默认连接第三方服务，不把该路线写成完成。

## 本轮工程交付

- Windows 后端全套 249 项通过、1 项跳过；暂停与 worker 诊断有定向检查。真实模型回退研究 8 次调用、111.3 秒：京东本地返回暂停，随后淘宝搜索/加入/详情读取，最终 `needs_evidence`。容量目录中可选 500ML 不等于已经选中；品牌和价格绑定仍未知，不能列为合格替代。
- worker 失败保留安全分类：`invalid_snapshot`、`browser_timeout`、`browser_error`、`oversized_snapshot`、`worker_exception`；字段校验只返回结构位置和错误类型，不返回输入、额外键内容或原始异常字符串。进程崩溃/无结果仍保留 `worker_failed`。
- 暂停和工具内部错误不再建议重新登录。暂停快照属于程序访问状态，不能证明商品属性、品牌或不存在替代品。
- 后续本轮优先完成淘宝/天猫闭环与交付验收；京东资料补充和接口方案留待恢复该路线时评审。京东完整在线详情核验与真实合格替代结论仍未完成。
